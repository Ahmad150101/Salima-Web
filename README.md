# Salima-Web

موقع إلكتروني تعريفي لعرض منتجات شركة سليمة، وأقسام المنتجات، والعلامات التجارية، والعروض، وتفاصيل المنتجات.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل المشروع باستخدام Live Server في Visual Studio Code.

## أهم المزايا

- واجهة عربية وإنجليزية مع تغيير اتجاه الصفحة تلقائيًا.
- وضع فاتح وداكن محفوظ داخل `localStorage`.
- بحث مباشر وتصنيفات للمنتجات.
- بطاقات منتجات مولدة من JavaScript.
- نافذة تفاصيل لكل منتج.
- معرض صور مع عارض Lightbox.
- قائمة هاتف متجاوبة وتحديد القسم الحالي.
- حركات ظهور وتحسينات وصول وأداء.
- صور SVG توضيحية خفيفة تعمل دون اتصال.

## تعديل المنتجات

كل بيانات المنتجات موجودة في:

`js/products.js`

يمكن تعديل الاسم والوصف والتصنيف وبيانات الاستخدام والتخزين والعبوة من هذا الملف فقط.

## استبدال الصور التوضيحية بالصور الرسمية

ضع صور العبوات الأصلية داخل:

`assets/products/`

ثم غيّر قيمة `image` للمنتج داخل `js/products.js`، مثال:

```js
image: "assets/products/rice.webp"
```

يُفضل استخدام صور `WebP` بخلفية شفافة وبأبعاد موحدة.

## ملاحظة مهمة

الصور الحالية وتصميمات العبوات والمعلومات التفصيلية توضيحية وليست مواصفات رسمية للمنتجات. يجب استبدالها بصور وبيانات الشركة المعتمدة قبل النشر النهائي.

## ربط دومين الشركة لاحقًا

الموقع يستخدم مسارات نسبية ويعمل حاليًا تحت مسار GitHub Pages:
`/Salima-Web/`.

عند اعتماد دومين رسمي:

1. حدّث الروابط المطلقة في وسوم Open Graph و`canonical` وJSON-LD.
2. حدّث روابط `robots.txt` و`sitemap.xml`.
3. أضف `CNAME` فقط بعد تأكيد اسم الدومين وإعداد DNS.
4. لا تغيّر المسارات النسبية للصور وCSS وJavaScript.

لا يتضمن المشروع حاليًا دومينًا أو عنوانًا أو وسيلة تواصل غير مؤكدة.
